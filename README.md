# Future You - Body Visualizer

Hackathon project: a health visualiser that shows how everyday lifestyle habits could affect your body and organ risk over time.

## Features

Adjust lifestyle habits and see the effect on an organ risk diagram.

Use the timeline slider to see how risk could change in the future.

## Tech stack

React, TypeScript, Vite, Tailwind, Supabase

## Run locally

```
npm install
npm run dev
```
